# Kehinde Ogunde

Personal portfolio and CV. Static HTML and CSS for the GitHub Pages user site, served from the default branch root.

## Preview locally

```bash
python3 -m http.server 8080
```

Open [http://127.0.0.1:8080](http://127.0.0.1:8080).

## GitHub Pages

Publish from the default branch at `/` (root). `.nojekyll` is included so Pages serves the files as-is, with no Jekyll build. `CNAME` sets the custom domain to kehindeogunde.com.

The CV download is [assets/Kehinde-Ogunde-CV.pdf](assets/Kehinde-Ogunde-CV.pdf).

Keztrip links to [keztrip.com](https://keztrip.com/), plus the Google Play and App Store listings that the site itself points to. MBL HighTech and Incentive Games cards have no outbound links; public pages for those CV names were not verified. Andela cards in Earlier projects link to the matching repositories under [github.com/coach-K](https://github.com/coach-K). Homie has no verified store URL; see the TODO comments in `index.html`. The Writing section links the verified Medium article only.
